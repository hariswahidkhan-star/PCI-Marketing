# Prompt for Claude Code — PCI AI SEO implementation

Copy everything below the line into Claude Code, opened in the `PCI` repository. It is
self-contained: every tag, rule and change is in the prompt. If the `PCI-Marketing` repository is

---

You are implementing the SEO changes for the Project Controls Institute platform in this repository.

## Facts

- The public website is live at **https://pciai.org**. The student portal is live at
  **https://mypci.org/student**. The legacy domain **projectcontrolsinstitute.org** must 301 to
  pciai.org page-for-page. Treat pciai.org as the canonical host everywhere.
- The site is a server-rendered ASP.NET Core 8 minimal API (`backend/`) serving ~235 static pages
  from `backend/wwwroot` with database-driven injection. Read `CLAUDE.md` first. Do not rebuild
  the site, do not add a framework, do not convert pages to Bootstrap.
- The `pages` table is seeded from `backend/schema.sql` with titles and descriptions, and
  `Core/PageContent.cs` injects `pages.title`, `pages.meta_description` and `pages.canonical_url`
  over the file. Every metadata change must be made in the file, in the `pages` row, and in the
  `schema.sql` seed row (then run `python3 tools/sqlite_to_mysql.py`).
- The live `/sitemap.xml`, `/sitemap-index.xml`, `/robots.txt` and `/llms.txt` are generated by
  `Core/Sitemap.cs` and `Core/AiVisibility.cs` from `Redirects.CanonicalBase`; the static files in
  `wwwroot` are fallbacks.

## Rules you must not break

- Never write "accredited", "ANAB", "IAS" or "ISO/IEC 17024 certified". The only permitted wording is "built to align with ISO/IEC 17024".
- Never state 501(c)(3) as a fact. The site's wording is "pursuing 501(c)(3) recognition, not yet granted".
- Never write "recognised by", "endorsed by" or "approved by" any government, employer or body.
- No salaries, pass rates, member counts or any number the site does not already publish.
- The honorary route is "Honorary Fellow (PCI)", a recognition. Never "honorary certification".
- There is no "PCP-AI". The credentials are PCL-AI, PFL-AI and PML-AI (plus the AIPC specialist certificate). Never create a page for PCP-AI.
- British spelling throughout. One primary keyword per page, used once in the title, once in the H1 and once in the first 100 words, never stuffed.
- Do not touch e-mail addresses on the old domain. Do not change the secure-exam API host. Do not
  create accounts, post anything, deploy, or touch Search Console.
- Work on a new branch `seo/pciai-domain-and-audit` from `origin/main`. Commit in the steps below.
  Open a draft PR at the end whose description lists each step as done, skipped or blocked, with
  the check output for each.
