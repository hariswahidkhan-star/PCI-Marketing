## 4. ⚠ info@pciai.org does not appear anywhere in the platform

PCI asked for this address and it is used in all ten films. It is on a genuine
PCI domain, so nothing about it is wrong. But:

- The platform uses **`hello@projectcontrolsinstitute.org`** in **456** places.
- `info@pciai.org` appears in **zero** files.
- `pciai.org` is not referenced by any page on the live site.

**Before publishing, confirm the mailbox exists and someone reads it.** A
campaign address that bounces costs more than the campaign returns, and every
one of these films ends on it. If it is not set up, either create it or say the
word and the films can be re-rendered against
`hello@projectcontrolsinstitute.org` — it is one string in one shared file.

## 5. How the offer is presented, and why that way

The offer is real and generous, which is exactly why it is presented plainly.
A genuine free offer from a young institute is far more likely to be mistaken
for a scam than a modest one, so the films do the opposite of hype:

- **The code is shown, spelled and held on screen** — `FOUNDINGFREE`, in
  capitals, because the platform uppercases input before it looks the code up
  and a lower-case stored value would never match. See `OFFER-SPEC.md`.
- **What it grants is stated exactly**: membership, study access and exam
  enrolment — the three things the schema says a founding code grants. Not
  "everything", not "lifetime", neither of which is true.
- **No countdown, no invented scarcity, no "act now".** If there is a genuine
  cap or end date, it should be stated as a fact; until PCI sets one, the films
  say nothing about limits rather than manufacturing urgency.
- **No claim that it is instant.** Redemption needs an account first, so the
  films say *apply the code*, not *click and you are in*.
- The word **founding** carries the honest reason the offer exists: it is early.
  That is a better and more durable argument than a discount.

## 6. Framing, not fact

These are argument and are written so they cannot be read as measurable claims:

- "AI proposes. The professional disposes." — PCI's stated governing principle,
  quoted as such.
- Statements that project controls is changing, that judgement matters, and
  that credentials should be verifiable. Opinion, offered as opinion.
- The films do not say PCI is the answer to any of it. They say what PCI is and
  what it costs right now.

## 7. Media provenance

is drawn from the platform's own design tokens — Archivo, Inter, the navy
ground, the crimson-to-blue rule. Nothing depicts a real person, and no
testimonial, endorsement or named individual appears in any of the ten.
